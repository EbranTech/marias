# Feliz cumpleaños, niña berrinchuda

Sitio estático mobile-first creado con HTML, CSS y JavaScript. Está diseñado para publicarse directamente mediante GitHub Pages.

## Probar localmente

Desde esta carpeta, puede iniciarse un servidor local con:

```powershell
python -m http.server 8000
```

Luego abre `http://localhost:8000` en el navegador.

## Publicación

El sitio no requiere compilación. GitHub Pages puede servirlo directamente desde la raíz de la rama `main`.

> Las fotografías, videos y canciones de este repositorio son material personal. Al publicar el sitio y el repositorio, estos archivos pueden quedar accesibles públicamente.
